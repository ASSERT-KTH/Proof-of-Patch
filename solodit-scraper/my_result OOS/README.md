in_scope.json represents the in_scope audits for this thesis project.

The data gathering resulted in many audits found in multiple search categories. These were removed and then marked as duplicates with #dupe.

Thus, all audit links in in_scope.json marked with #dupe, were originally found in multiple search categories.

The reason for the #dupe flag, is for the auditor (me) to know that they were included in multiple search categories, and thereby keep in mind that the audit may fit better under a different OWASP top 10 vulnerability category than it currently is included in.
